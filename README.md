# Карта объектов теплоснабжения — демонстрация

Карта в двух видах из одних данных: интерактивная для сайта и макет для печати
на стену 2,5 × 1,5 м. Собрана на открытых данных, чтобы её можно было проверить,
а не поверить на слово.

**Что показано**

- точки объектов с карточкой по клику;
- покрытие по регионам — заливка по числу объектов, ступенями, чтобы соседние
  регионы можно было сравнить глазом;
- тепловая подложка — честная плотность: каждая точка даёт гауссово пятно, пятна
  складываются, шкала растягивается по итоговому максимуму;
- печатный макет в векторе: границы, точки и подписи остаются резкими при любом
  увеличении.

**Данные:** объекты — [Wikidata](https://query.wikidata.org), границы регионов —
[Natural Earth](https://www.naturalearthdata.com), подложка — © OpenStreetMap
contributors.

**Как собрано**

```
python build.py        # точки, привязка к регионам, плотность
python render.py       # растровые макеты (экран и печать)
python svg_map.py      # векторный макет 2,5 × 1,5 м
```

`map.html` — интерактивная карта (MapLibre GL), открывается как обычная страница.

**Оговорка.** Это демонстрация подхода, а не карта конкретного заказчика: взяты
открытые данные по объектам энергетики России. На таблице адресов заказчика
работа идёт так же — адреса геокодируются, выбросы просматриваются глазами,
дальше те же слои и тот же макет.
